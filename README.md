A make.fun bounty entry. `main.py` (Python 3, standard library only) writes
one line — a single joke about a meeting that should have been an email,
at most 200 characters — to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, falling back to `/output`).

## Run

```sh
python3 main.py
```

The entry text:

> The meeting ended when someone finally read the email aloud - the one that had cancelled the meeting 45 minutes earlier.
